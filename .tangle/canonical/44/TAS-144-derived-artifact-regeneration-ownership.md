# Context

Parent [[TAS-137-usage-feedback-hardening-round-seven]].

Hekate `FBK-022` at `0.6.0+g3bacaf5`: a later slice fixed behavior a resolved
slice owned so the later node's own deliverable would hold, which invalidated
derived artifacts the resolved slice had committed and a test it had written. The
reversal/supersession contract covers reversing an outcome in its own node and
superseding an outcome that moves to a new node, but not a later node changing
behavior a resolved node owns and regenerating that node's derived artifacts.

# Outcome

The reversal/ownership contract states that the node that re-derives a resolved
node's derived artifact performs the change, records the defect, the falsified
artifact, and the regenerated artifact names in its own `# Result`, leaves the
resolved node read-only, and admits a child or sibling when the change is
independently resumable, naming the resolved owner in its `# Context`.

# Done when

- The rule is in `SKILL.md` or `references/dependencies.md` and pinned by a
  contract test.
- Derived-artifact regeneration is reported like a golden regeneration.
- The rule states when the change instead warrants a child or sibling node
  naming the resolved owner.
- `make test` passes.

# Result

`references/dependencies.md`'s **Reversal and supersession** section now carries
the derived-artifact regeneration rule the `FBK-022` probe lacked, on the topic a
worker loads before pinning, reversing, superseding, or re-deriving:

- Ownership: a derived artifact a resolved node committed — a golden, baseline,
  snapshot, frozen measurement, or generated index — is regenerated by the node
  whose change invalidates it, not by reopening the resolved node. That node
  performs the change, records the defect, the falsified artifact, and the
  regenerated artifact names in its own `# Result`, and leaves the resolved node
  read-only, because a resolution is final and a committed artifact is re-derived
  by the change that invalidates it.
- Reporting: regeneration is reported like a golden regeneration — the
  invalidated artifact is a member of the change's write-set closure, so that
  node includes it, regenerates it, and reports the falsified artifact and the
  regenerated names instead of only reporting that the resolved node went stale.
- Slice ownership versus child or sibling: that node owns the regeneration while
  the regeneration stays one slice of its own outcome. When the regeneration is
  independently resumable — its own outcome, completion evidence, and rollback
  boundary — it is a child or sibling whose `# Context` names the resolved owner
  and whose `# Done when` carries the regeneration. A regeneration that cannot be
  executed faithfully is never approximated to fit: a frozen live measurement is
  re-recorded, or carried as that child or sibling, and never replaced by a
  dry-run artifact, a degraded measurement, or an unrecorded assumption.

That last clause is the documented handoff for the frozen
`benchmark/memory-authority-result.json` measurement the round's context named:
its seven observable prompt files under `src/tangle/` are untouched by this
slice, so the artifact stays valid and no live re-record is owed here. A later
change to an observable file owes a faithful re-record and cannot discharge it
with a dry-run or a degraded artifact.

`SKILL.md` extends the **dependencies** routing bullet to name regenerating a
resolved node's derived artifact, keeping the rule on the already-routed topic;
the core stays inside its size bound (14,498 bytes < 16,000).

Tests: `tests/test_skill.py` adds
`test_derived_artifact_regeneration_names_its_owner`, which pins
`_DERIVED_ARTIFACT_REGENERATION_RULE` — seven literal strings spanning the
ownership, read-only, reporting, closure, child-or-sibling, and faithful
re-record clauses — against `references/dependencies.md`, plus
`test_derived_artifact_regeneration_guard_rejects_the_supersession_alone`, whose
probe `_DERIVED_ARTIFACT_REGENERATION_PROBE_SUPERSESSION_ONLY` is the pre-change
supersession/deprecation paragraph: it settles the resolved-node shapes but
carries none of the rule strings, so the guard fails when it stops detecting the
rule rather than when the paragraph merely reflows.

`tangle check` passes and `make test` passes.
